# Задача на менторство. Golang

## Задание 1
Написать HTTP-сервер, который принимает запрос от клиента принимает числа 'a', 'b' и символ '+ - / *' . К HTTP-обработчикам добавить CRUD-методы. Результат сохраняется в БД Postgres и возвращается клиенту.

## Задание 2
Написать сервис (поднимается через docker compose):
### 2.1 
Перенести в него БД и её методы, чтобы 1-ый сервис стал HTTP-gateway и передавал данные во 2-ой с persistence.
### 2.2
Коммуникация Service 1 - Service 2 происходит по шине сообщений. Изучить отличия брокеров и выбрать один.
### 2.3
Сервис 1 по ручке GET получает данные не из БД, а из Cервиса 2 по gRPC.
